# chocofi-PCB

Kicad chocofi split keypoard pcb.
Total keys: 2 x 18.
Both parts are connected with bluetooth.
Firmware embeded is ZMK.
Each parts have USB-C.

## Conventions

- I don't want to edit anythings in the code ! Only suggest.

## Components

- For each key:
  - 1N4148WS
  - Hotswap socket Kailh CHOC V2
- USB C 16 pins
- E73 2G4M08S1C
- AP2112K-3.3
- MPC73831-2-OT
- USBLC6-2CS6
